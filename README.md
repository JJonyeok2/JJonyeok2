### 🙋 저는 이런 사람입니다

**💬 소통을 좋아합니다**
혼자 잘 만드는 것보다 함께 잘 만드는 쪽이 더 즐겁습니다.
팀원이 어떻게 일하는지 먼저 듣고, 모두가 편해지는 방법을 같이 찾습니다.

**🤖 AI와 함께 개발합니다**
AI를 단순한 자동완성이 아니라 함께 일하는 동료로 씁니다.
어떻게 일을 나누고 맡겨야 결과가 좋아지는지를 계속 실험하고 정리합니다.

**🧪 흥미로운 건 먼저 써봅니다**
새로운 도구나 방식이 보이면 일단 제 프로젝트에 넣어봅니다.
잘 모르는 분야여도 직접 부딪혀 보면서 배우는 걸 좋아합니다.

**👀 사용자의 자리에서 생각합니다**
"내가 만들고 싶은 것"보다 "쓰는 사람이 정말 편한가"를 먼저 묻습니다.
그 질문 때문에 방향을 통째로 바꾼 적도 있습니다.
