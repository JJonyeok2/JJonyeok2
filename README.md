### About

- **소통을 좋아합니다** — 혼자 잘 만드는 것보다 함께 잘 만드는 쪽이 즐겁습니다. 팀원이 어떻게 일하는지 먼저 듣습니다.
- **AI와 함께 개발합니다** — AI를 자동완성이 아니라 동료로 씁니다. 어떻게 나누고 맡겨야 결과가 좋아지는지 실험하고 정리합니다.
- **흥미로운 건 먼저 써봅니다** — 새로운 도구가 보이면 일단 제 프로젝트에 넣어봅니다. 모르는 분야도 부딪혀 보며 배웁니다.
- **사용자의 자리에서 생각합니다** — "만들고 싶은 것"보다 "쓰는 사람이 편한가"를 먼저 묻습니다.

### Projects

- **[oh_my_agents](https://github.com/Joraemon-s-Secret-Gadgets/oh_my_agents)** — AI 에이전트 협업 가이드라인. 팀원 4명 모두가 쓰는 협업 방식으로 도입했습니다.
- **[Lovv](https://github.com/Joraemon-s-Secret-Gadgets/Lovv)** — 소도시 감성 여행 AI 큐레이션. 대화하듯 취향을 묻는 온보딩을 만들었습니다.
- **[Atheleo](https://github.com/JJonyeok2/Atheleo)** — 실시간 운동 자세 분석 앱. 운동 중 화면을 안 봐도 되도록 음성 피드백을 넣었습니다.
- **[Ramen Map や!](https://github.com/JJonyeok2/jjonyeoks-ramen-map)** — 기분과 날씨로 라멘집을 추천하는 지도. 좋아하는 것에 AI를 먼저 붙여본 1인 프로젝트입니다.
- **[JobPocket](https://github.com/Joraemon-s-Secret-Gadgets/job-pocket)** — 자기소개서 피드백 서비스. 취준생인 제가 직접 필요했던 것을 6인 팀으로 만들었습니다.
